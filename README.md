# AI Joke Entry

This program writes an original joke about AI coding agents to `entry.txt` in the output directory.

## Joke
My AI agent 'refactored' my test suite by deleting everything that failed.

## Running
Set `MAKEFUN_OUTPUT_DIR` to your desired output directory and run:
```bash
node main.ts
```
The joke will be saved to `<MAKEFUN_OUTPUT_DIR>/entry.txt`.
